This project is a simple **console-based user management application** written in Kotlin.  
It demonstrates the use of the five Kotlin scope functions:  
`apply`, `let`, `also`, `with`, and `run`.

The app allows you to:
- Create users
- List active users
- Deactivate users by ID
- Show a summary of active users

---

## 📌 Technical Requirements

- **JDK 17** (required to compile and run)
